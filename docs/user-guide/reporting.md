# Read dashboards and investigate discrepancies

Use the right view for due work, census, stock and money.

**Who can do this:** All HMS staff for their permitted dashboards; Receptionist · Pharmacist · System Manager for HMS Reconciliation; pharmacy roles for stock

[All workflows](README.md)

## What this workflow does

Dashboard labels distinguish current operational counts from historic activity. Reconciliation explains invoice balances, while stock lots and movements explain quantities.

## Before you start

- Read access to the relevant records/report.

## 1. Check the definition

Reception shows new patients, visits on Visit date and Current Inpatients. Follow-ups shows due clinical dates; Fee Validity shows financial eligibility.

## 2. Read collections correctly

Accounts charts and Recorded Receipts show gross recorded Receive receipts before refunds. Drafts are excluded; Legacy Recorded receipts may still need allocation.

## 3. Use HMS Reconciliation

With Receptionist, Pharmacist or System Manager access, open HMS Reconciliation. Filter by Patient or Outstanding only. Compare Invoiced, Credits, Net Receipts, Outstanding and Refund Due. Different currencies are not added together. Doctor-only access does not include this report.

## 4. Trace stock differences

With Pharmacist or System Manager access, open HMS Stock Lot for current quantities and HMS Stock Movement for signed movements. Inspect the linked intake, dispensing or adjustment instead of changing the balance directly.

## 5. Investigate the source

For a missing or unexpected number, check date filters, status, currency, role permissions, source links and whether the record is Draft, Posted, Legacy or cancelled. Save corrections through the source workflow.

## What success looks like

The report definition, record states and underlying sources explain the displayed totals.

## Common problems and recovery

Empty charts can be correct on a new site or after restrictive filters. If data still disagrees, give an administrator the record IDs and expected calculation; do not send patient details through an unapproved channel.
