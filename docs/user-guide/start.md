# Find your way around

Find your workspace, records and help.

**Who can do this:** Receptionist · Doctor · Pharmacist · System Manager

[All workflows](README.md)

## What this workflow does

HMS uses Frappe Desk. Your assigned roles determine which records and actions are available. This guide explains operational tasks; it does not grant access.

## Before you start

- An existing staff login and assigned HMS role.

## 1. Open HMS

Sign in with your usual Frappe account and choose HMS from the app chooser. The removed custom React dashboard is no longer used.

## 2. Choose a module

Choose HMS Core, Reception, Clinical, Inpatient, Pharmacy or Billing from the HMS dock or module selector. Each module has its own sidebar, with expandable sections and links available to your roles. HMS Core contains Hospital Live, shared patient records and administration. User guide is at the bottom of every module sidebar.

## 3. Open a record

Use the relevant module sidebar, a dashboard shortcut or Desk search. Patients also appears in Reception and Clinical for convenience. Confirm the record ID as well as the patient name before changing anything.

## 4. Get help for the task

Choose User guide from a workspace or Help on a supported form. Search by a task, field, button or status; filter by category or role.

## 5. Read a walkthrough

Open a chapter and select an available screenshot to enlarge it. Where a GIF example is available, expand Watch walkthrough and choose Play walkthrough. Missing media is labelled pending. Use Print / save PDF for one chapter or Print all chapters for the full guide.

## What success looks like

The workspace and actions match your role. Empty lists and zero counts are normal on a new installation.

## Common problems and recovery

If an action is missing, refresh Desk and ask your System Manager to check roles and any site-specific permissions. Do not borrow another staff account.
